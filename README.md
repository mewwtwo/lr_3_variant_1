# ЛР 3, Варіант №1

Схема №1, `nt = 5`, `a=6, b=5, c=8, d=5, e=8, f=9, g=4, h=5, i=6, k=4`.

Паралельне виконання обчислення за схемою (орграф з мітками дуг). Кожна дія `f(x, i)` —
заглушка, що спить 1 секунду й виводить «З набору x виконано дію i.». Розподіл дій по
5 потоках і порядок виконання жорстко задані (hardcoded), синхронізація — через `std::latch`.

## Результат

Тривалість обчислення ≈ **13 секунд** — це теоретичний мінімум: набір `f` (9 дій) починається
лише після решти 51 дії, тому `ceil(51/5) + ceil(9/5) = 11 + 2 = 13` кроків.

| `src/` | сама програма |

### Залежності наборів

```
a -> e, g      b -> h, i
e -> k         g, h -> c        i -> d
k, c, d -> f
```

## Збирання і запуск

Потрібен компілятор з підтримкою C++20 (`<latch>`, `<syncstream>`, `<thread>`) і CMake.

### Термінал

```bash
cmake -S . -B build
cmake --build build
```
```
./build/prog > results.txt
```

> На macOS з Apple clang `<syncstream>` працює лише з прапорцем `-fexperimental-library`;
> він уже доданий у `CMakeLists.txt`. Для g++ цей прапорець не потрібен.
