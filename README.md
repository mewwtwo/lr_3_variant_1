# ЛР 3, Варіант №1

Схема №1, 5 потоків, `a=6, b=5, c=8, d=5, e=8, f=9, g=4, h=5, i=6, k=4`.

Паралельне виконання обчислення за схемою (орграф з мітками дуг). Кожна дія `perform_action(set_name, action_number)` —
заглушка, що спить 1 секунду й виводить «З набору x виконано дію i.». Розподіл дій по
5 потоках і порядок виконання жорстко задані (hardcoded), синхронізація — через `std::latch`.

## Результат

Тривалість обчислення ≈ **13 секунд** — це теоретичний мінімум.

Чому не менше:
- Набір `f` (9 дій) можна починати лише тоді, коли виконано всі решту 51 дію.
- 51 дію 5 потоків виконують за 11 секунд: 10 секунд по 5 дій (разом 50), і ще 1 секунда на останню дію.
- 9 дій набору `f` 5 потоків виконують за 2 секунди: 5 дій, потім 4.
- Разом 11 + 2 = 13 секунд.

### Залежності наборів

```
a -> e, g      b -> h, i
e -> k         g, h -> c        i -> d
k, c, d -> f
```

## Збирання і запуск

Потрібен компілятор з підтримкою C++20 (`<latch>`, `<syncstream>`, `<thread>`).

### macOS

```bash
cmake -S . -B build
cmake --build build
```

```
./build/prog > results.txt
```

Apple clang підтримує `<syncstream>` лише з прапорцем `-fexperimental-library`;
він  доданий у `CMakeLists.txt`.

### Windows

Використовується MinGW-w64 (g++ 11+) з MSYS2.
```bash
cmake -S . -B build
cmake --build build
```

```
./build/prog.exe > results.txt
```
